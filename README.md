# How to Call a REST API
## Overview 
This guide explains how to call a REST API using a GET request.
## Example request:
Method: GET
  Endpoint:https://api.example.com/users
## Steps:
* Open an API tool like Postman or a terminal
* Send a GET request to the endpoint
* Receive the response in JSON format
* Check the returned data
## Example response:
{
"id":1,
"name":"John Doe"
}
## Result
You successfully called a REST API and received data.
